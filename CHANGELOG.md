# Changelog

This project follows semantic versioning. Changes to distributed files, vendored code, permissions, or escalation rules are made here, visibly, and never by the agent editing itself.

## 1.2.0 - 2026-10-29

### Why a minor version

New capability (the featured set and `fx.py list --featured`) and two fixes. Nothing was removed or renamed.

### Added

- **Featured set**: 50 picture effects, picked after rendering every verified picture effect at 1080x1920 on real vertical talking-head footage and judging the results. `featured.json` holds the picks and what each is for; `docs/effects/featured.md` is generated from it. `scripts/build_catalog.py` and the validator refuse a featured effect that is not verified, and any count other than 50.
- `fx.py list --featured`, and `featured` and `featured_use` on every catalog entry.
- `effects-catalog-and-selection` 1.2.0 starts from the featured set and asks for a reason in the plan for anything outside it.
- Eval `142-prefer-featured-effects` and three tests for the featured set.

### Fixed

- `lower-third` used fixed pixel sizes, so at 1080x1920 the name bar was a few pixels tall. It now scales with the frame.
- `rec-hud` sized its type by frame height, so in a vertical frame "REC" ran into the timecode. It now uses the shorter side, which leaves landscape renders unchanged.
- Both passed the 12-check gate again.

### Found in the review, not changed

- `letterbox-bars` targets a cinema aspect ratio, which on a vertical frame leaves a thin strip. That is what the effect does; it is not featured.
- Effects too subtle to see at default on high-key indoor footage (`teal-orange`, `skin-soft`, `late-night-cool-grade` and others) stay verified and are not featured.

## 1.1.0 - 2026-10-27

Release status: edit-and-render release with an effects library. The exact verified count and the full or limited release status are in the README, generated from the verification records.

### Why a minor version

Every 1.0.0 contract field, owned path, skill name, template, and test is still present. Nothing was removed or renamed, and the only change to existing contracts is new optional fields. Under semantic versioning that is a minor release. A removal or rename would have made it 2.0.0.

### Added

- **Effects library**, `skills/video-effects-core/effects-library/`: a catalog of picture effects across eight families plus audio effects, each with its source, a verification record, a reference still, and a contact sheet. `catalog.yaml` and `docs/effects/catalog.md` are generated by `scripts/build_catalog.py`.
- **Three build routes**, in order: effects HyperFrames ships (media effects, color presets and grading, 14 shader transitions and crossfade, vfx kernels, audio effects); original effects in compositions (CSS and SVG filters, GSAP moves, canvas generators); and behavior studied clean-room from Concat (AGPL-3.0-or-later). No Concat code, shader, preset value, image, or name is in this repository.
- `fx.py`, the effects tool: list, show, apply, remove, instances, stack-check, check-plan, flash-check, contact-sheet, and verify. `fx-runtime.js` drives every original effect as a pure function of composition time.
- **The 12-check verification gate**, run from an installed temporary profile by `scripts/verify_effects.py`, with renders made with the network switched off. Only effects with a passing record count as verified.
- **WCAG 2.3.1 flash check**, with thresholds quoted from the W3C pages read on 2026-10-21, and a version that checks known strobes in the test suite.
- 17 effects skills under `skills/video-effects-core/`. `edit-style-analysis` now also writes reference style notes for a single reference video (the brief's `reference-style-analysis`, added to the existing skill rather than duplicated).
- Templates: `reference-style-notes.yaml`, `effect-plan.yaml`, `effect-recipe.yaml`, `effect-verification-record.yaml`.
- Contract fields: `effect_preferences`, `effects_requested`, `effect_approver` on the task; `effect_plan_reference`, `effects_used`, `effect_versions`, `photosensitivity_result` on the result. Edit state `effect_plan_approved`, status `effect plan recorded`.
- Owner effects in `local/effects/` and owner recipes in `local/effect-recipes/`, preserved on update and never shipped.
- Docs: effects catalog, reference study, clean-room process, verification, performance, the Concat safety review, and photosensitivity and accessibility.
- `scripts/copy_check.py`: salted shingle and image hashes of the studied project, checked in CI. It also fails on the project's name outside the files allowed to name it.
- Validation: catalog fields, verified claims backed by records, README count equal to the verified count, deterministic and offline effect scripts, the copy check, and sync-conflict duplicates.
- Tests: `tests/test_effects.py` (catalog, apply and remove round trips, stacking, plan checks, flash check, copy check). The install tests cover the effects skills, owner effects and recipes surviving an update, and how each Hermes version treats a retired skill on update.

### Changed

- HyperFrames re-pinned from `v0.8.138` to `v0.8.183` (commit `7e2817619f340f9302eeaef185e73be39a19858d`) through the vendor pipeline: import, derive, lock, verify. Every patch applied unchanged. The toolchain lockfile adds `@hyperframes/shader-transitions@0.8.183`.
- Tested on Hermes 0.21.4 and 0.22.5. `hermes_requires` stays `>=0.21.4`.

### Fixed

- The install tests now import Hermes only from `HERMES_SRC`. Before, a module missing from the release under test could load from an editable Hermes install in the same venv. A new check fails if anything else is imported.

### Upgrade notes

Run `hf setup --install-cli` once after `hermes profile update video-editor`, because the HyperFrames pin changed. See the README's upgrade section for how Hermes 0.21 and 0.22 treat a retired skill on update.

## 1.0.0 - 2026-10-06

Release status: edit-and-render release.

### Added

- The `video-editor` Hermes Profile Distribution: identity, provider-neutral configuration, routing description, and a narrow `distribution_owned` allowlist.
- 25 post-production skills under `skills/video-editor-core/`, from intake to weekly review.
- The outlier-first workflow: outlier scoring relative to each account's own baseline, contrast sets, style blueprints with evidence tags, three-option style-match proposals, and a recorded style decision or one-edit waiver.
- `editor-hyperframes`, the wrapper skill, with a pinned launcher (`hf.py`) and deterministic measurement tools (`editor_tools.py`).
- HeyGen HyperFrames `v0.8.138` (commit `0ca28db4f8671a2e2262594e03c566222d695920`) as a derivative with recorded patches: 15 published skills and the internal `captions-overlay` skill, with a lock file of every checksum, patch, removed file, and asset license.
- Launcher gates: pinned CLI from a lockfile, self-update and telemetry switches, subcommand allowlist, workspace boundary, reference-folder exclusion, style-decision preflight, timed-media id check, rights and footage checks before a final render, worker planning from measured memory, and render receipts.
- 23 templates, with field names shared with the `social-media` profile where the two exchange work.
- Tests: measurement tools against synthetic ground truth, launcher gates against a stand-in CLI, installation and update on Hermes 0.21.4 and 0.21.5, a Kanban exchange with a temporary `social-media` profile, and renders of every claimed editing operation checked by pixel and by audio measurement.
- 82 synthetic behavior evaluation fixtures.
- Platform specifications and terms of service, each recorded with its URL and access date.

### Not shipped, on evidence

- `connected_research` mode. No platform passed every condition.
- `approved_external_services` mode. No hard action gate can be built inside one operating-system user.
- `music-to-video` and `product-launch-video`, and the internal skills `motion-doctrine`, `cut-the-curve`, and `seam-craft`.
- Background removal. Its runtime package and model are not in the pinned lockfile.

### Known limits

- The bundled upstream workflows were loaded in an installed profile and not rendered end to end.
- Long-form was tested at draft quality on one machine.
- Renders and installs were tested on macOS with Apple silicon only. CI runs the measurement and launcher-gate suites on Ubuntu.
